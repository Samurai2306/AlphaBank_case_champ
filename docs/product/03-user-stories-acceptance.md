# User Stories и Acceptance Criteria

Формат: Story → AC (Given/When/Then). Приоритет: P0 = demo must, P1 = demo should / prod phase 1–2.

---

## US-01 Onboarding через чат (P0)

**Как** начинающий мастер beauty, **хочу** рассказать о бизнесе в чате, **чтобы** не заполнять длинную анкету.

**AC:**

1. Given новый пользователь, When пишет «Делаю маникюр, ~200к/мес, Казань», Then система извлекает сферу, оборот, город и показывает `OnboardingSummary`.  
2. Given неполный ответ, When данных мало, Then агент задаёт ≤2 уточняющих вопроса, не стену текста.  
3. Given summary, When пользователь подтверждает, Then профиль сохраняется и CJM-уровень ≥1.

---

## US-02 Расчёт налога (P0)

**Как** самозанятая, **хочу** понять сколько отложить за месяц, **чтобы** не получить сюрприз.

**AC:**

1. Given профиль НПД и мок-выручка, When «Сколько налогов в этом месяце?», Then intent `TAX_CALC` и карточка `TaxCard` с суммой, ставкой, периодом.  
2. Then в ответе есть дисклеймер ИИ.  
3. Then при наличии RAG — ссылка/id источника; иначе явный «по расчётной модели демо».  
4. When пользователь просит платёжку, Then `PaymentDraftCard` без исполнения перевода.

---

## US-03 Unit-экономика (P0)

**Как** мастер, **хочу** понять точку безубыточности, **чтобы** знать сколько клиентов нужно в день.

**AC:**

1. Given аренда/расходники/цена услуги, When считает unit-экономику, Then `UnitEconomicsChart` + число «N клиентов/день».  
2. Then формулы прозрачны (показать исходные входы).

---

## US-04 ЕНП-копилка (P0)

**Как** предприниматель, **хочу** автоматически откладывать % с поступлений, **чтобы** не тратить налоговые деньги.

**AC:**

1. Given включена копилка 6%, When приходит мок-поступление 10_000, Then в копилке +600 и виджет `EnpPiggyBank` обновлён.  
2. When копилка выключена, Then отчислений нет.

---

## US-05 Светофор контрагента (P0 demo / P1 prod)

**Как** ИП, **хочу** проверить контрагента до перевода, **чтобы** не словить 115-ФЗ.

**AC:**

1. Given ИНН, When `check_counterparty_risk`, Then `ComplianceTrafficLight` green/yellow/red + краткая причина.  
2. Given red, When пользователь всё же создаёт draft, Then UI показывает предупреждение и требует явное confirm.

---

## US-06 Legal Scanner (P1)

**Как** мастер, **хочу** загрузить договор аренды, **чтобы** увидеть красные флаги.

**AC:**

1. Given PDF ≤10MB, When upload, Then список `LegalFlagsList` с цитатами фрагментов.  
2. When PDF битый, Then понятная ошибка, без падения чата.

---

## US-07 Подтверждение платежа (P0 demo / P0 prod stricter)

**Как** пользователь, **хочу** подтвердить черновик, **чтобы** случайно не отправить деньги.

**AC Demo:**

1. Confirm только меняет статус draft→confirmed_mock, без внешнего API денег.

**AC Prod:**

1. Confirm требует SMS/Push или биометрию.  
2. Без прохождения validator money-action не уходит в core.

---

## US-08 Proactive alert кассового разрыва (P2 prod)

**Как** владелец точки, **хочу** узнать за 14 дней о риске нехватки на аренду, **чтобы** взять овердрафт заранее.

**AC:**

1. Given Kafka-события баланса и календарь аренды, When ML-сигнал, Then push + сообщение Copilot с оффером (policy-gated).  
2. Then пользователь может отказаться в один тап.

---

## US-09 Голос (P1)

**Как** мастер с занятыми руками, **хочу** говорить, а не печатать.

**AC Demo:** Web Speech → текст в чат.  
**AC Prod:** Voice pipeline банка + те же agents.

---

## US-10 Доверие и отказ (P0)

**Как** банк, **хочу** чтобы ИИ не давал советы по уклонению от налогов.

**AC:**

1. Given jailbreak/prompt injection, When input guard, Then отказ + предложение легальных опций.  
2. Given вопрос вне компетенции, Then handoff/уточнение, не галлюцинация закона.
