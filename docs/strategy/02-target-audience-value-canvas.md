# Целевая аудитория и Value Proposition Canvas

## Сегменты

### Primary — Beauty masters (самозанятые / «в серую»)

- **Кто:** женщины 17–25 (ядро), расширенно 18–35; маникюр, ресницы, частные мастера.
- **Контекст:** часть работает без регистрации; барьеры — незнание налогов, сложность оформления, желание максимизировать «здесь и сейчас».
- **Задача банка:** сделать легализацию и уплату налогов **понятными, простыми и выгодными**.

### Secondary — Beauty business / retail / beauty-медицина

- Салоны, небольшая розница косметики, кабинеты (косметология).
- Боли: ККТ, отчётность, найм, кассовые разрывы, 115-ФЗ при оборотах.

### Tertiary (фаза 2+)

- HoReCa, e-commerce селлеры (из Master Strategy).

## Инсайты из качественного исследования

1. Банк открывают не «ради банка», а ради **грантов / господдержки / официального счёта** (личную карту не принимают).
2. Налоги и обязательные платежи при нулевом доходе — **непрозрачны и пугают**.
3. Ожидание: **всё в одном приложении** — документы, подсказки, поддержка без внешних сервисов.
4. UX = доверие деньгам: «не доверю деньги компании с плохим интерфейсом».
5. Переключение с Т-Банка только если продукт **значительно лучше** (онлайн-бухгалтерия + ясность).
6. Фрагментация инструментов — главная системная боль старта.

## Value Proposition Canvas

### Профиль клиента (круг)

| Блок | Содержание |
|------|------------|
| **Customer Jobs** | Зарабатывать на услугах; принимать оплату; не получить штраф; понять, сколько откладывать на налог; выглядеть «официально» для клиентов/аренды/грантов; вести запись клиентов |
| **Pains** | Страх ФНС; сложные документы; «бухгалтер — дорого»; смешение личных и бизнес-денег; кассовый разрыв перед арендой; блокировки 115-ФЗ; непонятные тарифы банка |
| **Gains** | Прозрачная сумма налога «на пальцах»; чувство контроля; экономия времени; доступ к эквайрингу/терминалу; статус «белая»; рост через понятную unit-экономику |

### Карта ценности (квадрат)

| Блок | Содержание |
|------|------------|
| **Products & Services** | AI Copilot в Альфа-Бизнес; РКО; эквайринг/терминал; ЕНП-копилка; онлайн-регистрация НПД/ИП; проверка контрагентов; черновики платежей |
| **Pain Relievers** | Онбординг голосом/чатом без анкет; Tax Calculator с суммами и датами; Legal Scanner красных флагов; светофор 115-ФЗ до платежа; дисклеймеры + ссылки на НК; низкий порог входа (Freemium) |
| **Gain Creators** | Generative UI (карточки налогов/платежек); проактивные алерты; unit-economics график; путь «серый → НПД → ИП» как трекборд; предложение овердрафта до кассового разрыва |

## Роль Альфа-Банка в жизни ЦА

Не «счёт для галочки», а **бизнес-кофаундер**: помогает начать легально, принимать платежи, не утонуть в налогах и дожить до второго года — тогда bank products становятся привычкой.

## Выбор 2–3 отраслей (обоснование)

1. **Beauty masters** — максимальная боль легализации + объём самозанятых + платежи (СБП/эквайринг).
2. **Beauty retail / кабинеты** — связка с терминалами и оборотом.
3. **HoReCa (пилот+)** — из приоритетов кейса; после валидации beauty-паттернов.
