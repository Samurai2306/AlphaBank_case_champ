# Конкурентный анализ и SWOT

## Конкуренты

| Игрок | Сильные стороны | Слабые стороны → наша возможность |
|-------|-----------------|-----------------------------------|
| **Т-Банк** | Лучший UX, сильная онлайн-бухгалтерия, фокус e-com/инфобиз | Нет глубокого предиктивного ИИ-наставника; боты по скриптам |
| **СберБизнес** | База, кредиты с господдержкой, отраслевые решения | Тяжёлый UX, бюрократия, низкая лояльность Gen Z, страх «госконтроля» |
| **Точка** | Фокус на предпринимателях, саппорт, комьюнити | Слабее сложное кредитование; нет экосистемы физлиц для B2B2C |
| **Небанковские AI** | ChatGPT, наловые боты, Notion AI | Нет денег/платежей/комплаенса; риск галлюцинаций; нет РКО |
| **Yclients / CRM** | Запись клиентов beauty | Нет банка, налогов как продукта банка, эквайринга «в одном» |

## SWOT Альфа-Банка с Copilot

| | |
|--|--|
| **S** | Сильный розничный бренд; карта Альфы у ЦА; потенциал бесшовного Физлицо→ИП; Платежный бизнес (эквайринг, терминалы) |
| **W** | Нужно переучивать поддержку; высокий cost разработки AI; риск «ещё одного чата» |
| **O** | 10+ млн самозанятых; 1.5–2 млн у лимита НПД; тренд AI-native UX; чемпионат/бренд «Альфа Будущее» |
| **T** | Регуляторика ЦБ/ФНС; репутация при ошибке ИИ по налогам; конкуренция UX Т-Банка; требования on-prem |

## Позиционирование

> Альфа — банк, с которым начинается бизнес: ИИ закрывает страхи налогов и документов, а Платежный бизнес принимает деньги — в одном пути.

## Вывод для продукта

Чтобы перебить Т-Банк, нужно быть **значительно лучше** в связке: ясность налогов + actionable GenUI + превентивный 115-ФЗ + путь легализации, а не паритет «ещё одной онлайн-бухгалтерии».
