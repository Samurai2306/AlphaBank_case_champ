# Риски и compliance

## Матрица рисков

| Риск | Угроза | Митигация |
|------|--------|-----------|
| **AI Hallucinations** | Неверный налог → штраф клиенту → репутация банка | Strict RAG + цитата статьи НК; отказ при низком confidence; дисклеймер «ИИ-помощник, решение за вами» |
| **Data Privacy** | PII/транзакции в публичном LLM | Production: on-prem Llama/Qwen/Mixtral; NER masking до инференса; demo: синтетические данные + opt-in |
| **Регуляторика ЦБ/ФНС** | Банк как «неофициальный налоговый агент» | Официальные API ФНС/СМЭВ; не обещать юр. силу совета; сертификация ПО |
| **Репутация / jailbreak** | Советы по уклонению от налогов | Input guard (Llama Guard); политика отказа; логирование |
| **Платежи без контроля** | ИИ инициирует перевод | Hardcoded validator + SMS/Push/биометрия; GenUI только draft |
| **UX overload** | «Слишком умный» интерфейс пугает | Progressive disclosure по CJM-уровню |
| **Vendor lock cloud LLM** | Несовместимость с банком | Абстракция провайдера с day-1; контракты tools/SDUI стабильны |

## Ограничения пространства решений (кейс)

1. На уровне идеи внешние AI допустимы; финальное решение — совместимо с инфраструктурой и требованиями Альфы.
2. Решение не создаёт репутационных, юридических или иных рисков для банка.

## Guardrails (обязательные в архитектуре)

См. [../architecture/07-security-guardrails.md](../architecture/07-security-guardrails.md):

- PII masking
- Strict output parser для money-actions
- Anti-jailbreak
- Human-in-the-loop
- Audit trail действий ИИ

## Роль ИИ (критерии оценки кейса)

1. ИИ решает конкретные боли молодых предпринимателей.
2. ИИ встроен в путь предпринимателя.
3. Ясна польза клиенту и банку.
4. Связь с продуктами Платежного бизнеса.
5. Реалистично в банковском контексте.
