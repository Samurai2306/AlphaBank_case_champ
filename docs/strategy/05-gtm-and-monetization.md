# Go-to-Market и монетизация

## GTM (не классический Performance «открыть счёт ИП»)

1. **EdTech** — Skillbox / Практикум / Нетология: AI-калькулятор Альфы в дипломных проектах курсов «Косметолог», «Менеджер маркетплейсов».
2. **Shorts/Reels/TikTok** — серия «Бизнес с ИИ»: за 2 минуты закрыли налог/черновик декларации на экране.
3. **Партнёрства и франшизы** — пакет «в коробке» (счёт + финмодель); для beauty — школы мастеров, поставщики расходников.
4. **Community** — Альфа-клубы для Gen Z: вход = открытый путь в продукте, кейсы выросших на Copilot.
5. **Чемпионат / пилот** — демо как proof; пилот в 1–2 городах на beauty.

## Воронка

```
До-банковский инструмент (unit-экономика / налог)
  → Онбординг-чат (без анкеты)
  → НПД или ИП
  → РКО + эквайринг
  → ЕНП-копилка (привычка)
  → Cross-sell: ЗП, овердрафт, Pro
```

## Монетизация

Copilot на старте — **Retention & Cross-Sell**, не отдельная касса.

| Тариф | Содержание | Цель |
|-------|------------|------|
| **Basic (free)** | Налоги Q&A, календарь, регистрация, базовые виджеты | Доля рынка |
| **Непрямая** | Комиссии эквайринга; ЗП-проект; валютный контроль селлеров | Оборот |
| **Pro** | BI, CRM (Yclients/Amo), автопромо, расширенный овердрафт | ARPU |

## KPI (12–18 месяцев)

| Метрика | Цель |
|---------|------|
| CAC | −25–30% vs классический performance |
| Activation (счёт → первая txn терминала) | +15 п.п. |
| Survival year-1 | +20% (через снижение «налогового шока» и кассовых разрывов) |
| Кредитное проникновение МСП | +35% от проактивных офферов ИИ |
| Demo/pitch | Завершённый сценарий beauty-мастера end-to-end без помощи оператора |

## Пилот РФ

- Юрисдикция и контент — только РФ (НК, НПД, УСН, 115-ФЗ, СБП).
- Внешние AI на этапе идеи допустимы; финал — совместим с контуром Альфы.
